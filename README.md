# KAF Coffee — Islamabad Website

A responsive static website built from the supplied full-page visual direction.

## Included
- Full long-form homepage matching the dark/cream/gold KAF aesthetic
- Responsive mobile navigation and stacked cards
- Original AI-generated café/product photography included locally in `assets/`
- No Google Maps, Instagram, or business-listing screenshots are used as website imagery
- Clickable phone, Instagram and Google Maps direction links
